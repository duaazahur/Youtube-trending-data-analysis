# YouTube Trending Data Analysis
YouTube Trending Data Analysis using Python and Pandas — Master's Data Science project.

## Project Overview

This project analyzes YouTube trending video data from multiple countries using Python and Pandas.

The project was completed during my first semester of the Master's in Data Science as part of the Foundations of Computer Science course.

## Objectives

The analysis explores different aspects of YouTube trending videos, including:

- Video views, likes and dislikes
- Videos without tags
- Channel popularity
- Video engagement
- Publishing time patterns
- Tag frequency and performance
- Trends across different countries
- Trends over time
- Video categories

## Analysis

The project includes the following analyses:

1. Loading and combining YouTube datasets
2. Identifying videos without tags
3. Comparing total views by channel
4. Identifying and excluding problematic videos
5. Calculating the ratio between likes and dislikes
6. Grouping publishing times into 10-minute intervals
7. Analyzing videos and engagement by publishing interval
8. Counting the frequency of video tags
9. Finding the most frequently used tags
10. Comparing tag performance across countries
11. Finding the most-viewed trending video for each date and country
12. Extracting year, month and day from trending dates
13. Finding the most-viewed video for each month and country
14. Working with YouTube category information from JSON files
15. Analyzing videos with unassignable categories

Each analysis is documented directly in the Jupyter Notebook with the question being investigated, the Python code, and the resulting output.
